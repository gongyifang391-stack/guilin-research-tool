# Guilin ICH Research Tool

## 项目介绍

本项目是研究桂林非物质文化遗产国际传播的本地 Python 工具。
程序在研究者自己的电脑上运行，不提供在线登录或在线采集服务。

## 研究范围

检索北京时间2025年1月1日至2025年12月31日期间发布的相关公开视频。

检索词依据桂林非遗名录建立，包含全部205个不同的英文项目名，
以及中文名称和地域相关补充词。

检索结果按视频ID去重，并由研究者人工筛选相关性，
不保证涵盖平台全部相关视频。

## 采集内容

通过 YouTube Data API 获取：

- 视频标题、链接、发布时间、文字介绍和话题标签；
- 观看量、点赞量和评论总数；
- 可访问的评论正文及回复；
- 发布频道名称、频道ID及公开订阅人数。

互动指标和订阅人数为采集时的累计数值，
不代表2025年年底的历史数值。
评论采集不限制评论发表年份。

## 运行方式

研究者在本地 PyCharm 中运行脚本，输入自己的 API 密钥。
程序保存采集进度，并将结果导出为本地 Excel 和 JSON 文件。
